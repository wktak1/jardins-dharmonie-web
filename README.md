# Jardins d'Eleusis

Crée un site internet multipage moderne, chaleureux, rassurant et parfaitement responsive pour l’établissement :

EHPAD Les Jardins d’Eleusis
364 bis route de Koé
Dumbéa, Nouvelle-Calédonie
Téléphone : 29 85 00
E-mail : [accueil@eleusis.nc](mailto:accueil@eleusis.nc)

Le site s’adresse principalement aux familles qui recherchent une solution d’accueil pour un proche âgé. Son objectif est de leur permettre de découvrir l’établissement avant une visite, de comprendre les différentes possibilités d’accueil et d’accéder facilement aux informations essentielles.

Le site doit donner une impression de sérieux, de transparence, de proximité et de bienveillance, sans utiliser un ton commercial excessif.

IMPORTANT

* Ne jamais inventer de tarifs, de prestations médicales, de valeurs, d’horaires, de partenaires ou de modalités d’admission.
* Lorsqu’une information n’a pas encore été fournie, utiliser un contenu provisoire clairement identifiable sous la forme : « Contenu à compléter ».
* Ne pas utiliser de faux témoignages, de fausses statistiques ou de faux avis.
* Ne pas utiliser de photographies génériques issues de banques d’images.
* Prévoir uniquement des emplacements pour les véritables photos et vidéos de l’établissement qui seront ajoutées ultérieurement.
* Ne pas afficher de résident identifiable sans autorisation.
* Ne pas créer de demande d’admission en ligne.
* Ne pas créer de newsletter.
* Ne pas créer pour le moment de rubrique recrutement ou de présentation détaillée de l’équipe, car ces éléments doivent encore être validés.
* Le site doit pouvoir fonctionner sans base de données, sans authentification et sans backend complexe.

IDENTITÉ VISUELLE

S’inspirer du logo des Jardins d’Eleusis, représentant un arbre stylisé.

Palette principale :

* vert végétal comme couleur principale ;
* orange chaleureux comme couleur d’accent ;
* crème et blanc cassé pour les arrière-plans ;
* gris foncé doux pour les textes ;
* éviter les noirs trop durs et les couleurs médicales froides.

Le design doit être :

* chaleureux et humain ;
* lumineux et aéré ;
* naturel, avec des formes légèrement arrondies ;
* élégant mais pas luxueux ;
* institutionnel sans être froid ;
* facile à parcourir pour des utilisateurs parfois peu à l’aise avec le numérique.

Éviter les effets technologiques, les dégradés excessifs, les animations envahissantes et l’accumulation de cartes.

Utiliser une typographie très lisible, avec :

* une taille de texte confortable, au minimum 17 ou 18 px pour les paragraphes ;
* des titres clairement hiérarchisés ;
* un contraste élevé ;
* des boutons suffisamment grands ;
* une navigation accessible au clavier ;
* des textes alternatifs pour les images ;
* une mise en page adaptée aux mobiles, tablettes et ordinateurs.

PAGE ACCUEIL

Créer une page d’accueil immersive et rassurante avec les sections suivantes.

1. En-tête

Afficher le logo, la navigation principale, le numéro de téléphone et le bouton de téléchargement du dossier d’admission.

L’en-tête peut devenir légèrement compact et rester visible lors du défilement.

2. Section principale avec vidéo

Prévoir un grand emplacement pour une véritable vidéo de présentation filmée par drone.

Le lecteur vidéo doit :

* se lancer automatiquement uniquement si le navigateur l’autorise ;
* être muet par défaut ;
* utiliser les attributs autoplay, muted, loop et playsInline ;
* disposer d’une image de couverture de secours ;
* ne jamais afficher un écran noir si la vidéo ne charge pas ;
* proposer un bouton permettant de lancer ou mettre en pause la vidéo ;
* fonctionner correctement sur iPhone, Samsung et autres appareils mobiles.

Superposer sur la vidéo ou son image de couverture :

Titre :
« Les Jardins d’Eleusis, un lieu de vie à Dumbéa »

Texte :
« Découvrez notre établissement, ses espaces de vie et les différentes solutions d’accueil proposées aux personnes âgées et à leurs familles. »

Boutons :

* « Découvrir l’établissement »
* « Télécharger le dossier d’admission »

3. Présentation courte

Créer une introduction rassurante présentant Les Jardins d’Eleusis comme un établissement d’hébergement pour personnes âgées dépendantes situé à Dumbéa.

Ne pas inventer les valeurs de l’établissement. Prévoir un emplacement intitulé :

« Les valeurs des Jardins d’Eleusis – contenu à compléter après validation »

4. Les solutions d’accueil

Présenter clairement les différentes possibilités :

* hébergement permanent ;
* hébergement temporaire ;
* accueil de jour.

Pour chaque solution, prévoir une courte présentation et un lien « En savoir plus ».

Ne pas inventer les conditions d’accès, les durées ou le nombre de places disponibles pour l’hébergement temporaire et l’accueil de jour.

5. Les trois unités d’hébergement

Créer trois blocs visuels avec une photo authentique à ajouter ultérieurement.

Les Niaoulis

* ouverture en 2013 ;
* 40 places ;
* chambres individuelles et doubles ;
* salle de bain partagée.

Les Fougères

* ouverture en 2019 ;
* 26 places ;
* chambres individuelles ;
* salle de bain privative.

Les Terrasses

* ouverture en 2019 ;
* 14 places ;
* unité UHR ;
* chambres individuelles ;
* salle de bain privative.

Prévoir un bouton « Découvrir nos unités ».

6. La vie aux Jardins d’Eleusis

Créer une section mettant en avant, sans exagération commerciale :

* les repas préparés sur place par une cuisinière dédiée ;
* le service de lingerie réalisé sur place ;
* les activités proposées ;
* les espaces de vie ;
* le cadre de vie ;
* le quotidien des résidents.

Utiliser uniquement des photos authentiques qui seront transmises par l’établissement.

7. Galerie mise en avant

Afficher un aperçu de plusieurs photographies, avec un bouton « Voir toute la galerie ».

Prévoir des catégories :

* bâtiments et extérieurs ;
* espaces communs ;
* chambres ;
* activités ;
* repas et moments de vie.

8. Admission

Créer une section simple expliquant que les familles peuvent consulter les informations utiles et télécharger le dossier d’admission.

Boutons :

* « Télécharger le dossier d’admission »
* « Consulter les tarifs »
* « Contacter l’établissement »

9. Localisation

Ajouter une carte Google Maps intégrée et chargée de manière différée pour ne pas ralentir le site.

Adresse :
364 bis route de Koé, Dumbéa, Nouvelle-Calédonie.

Ajouter un bouton « Ouvrir l’itinéraire ».

10. Pied de page

Afficher :

* logo ;
* adresse ;
* téléphone 29 85 00 ;
* e-mail [accueil@eleusis.nc](mailto:accueil@eleusis.nc) ;
* lien vers Facebook ;
* emplacements pour Instagram, TikTok et LinkedIn ;

* mentions légales ;
* politique de confidentialité ;
* plan du site.

PAGE L’ÉTABLISSEMENT

Créer une présentation structurée comprenant :

* l’histoire de l’établissement ;
* sa localisation à Dumbéa ;
* son évolution entre l’ouverture des Niaoulis en 2013 et celle des Fougères et des Terrasses en 2019 ;
* la présentation générale des espaces ;
* une section dédiée aux valeurs, laissée en attente tant que le contenu n’est pas validé ;
* une comparaison visuelle ou chronologique des bâtiments en 2013 et en 2019, avec des emplacements pour des photographies aériennes ;
* un lien vers la galerie.

Prévoir un emplacement pour un éventuel « Mot de la direction », sans rédiger de faux message.

PAGE NOS SOLUTIONS D’ACCUEIL

Présenter distinctement :

1. L’hébergement permanent
2. L’hébergement temporaire
3. L’accueil de jour

Ajouter ensuite une présentation détaillée des trois unités :

* Les Niaoulis ;
* Les Fougères ;
* Les Terrasses.

Pour chaque unité, prévoir :

* une photographie principale ;
* une galerie secondaire ;
* le nombre de places ;
* le type de chambres ;
* le type de salle de bain ;
* une description à compléter ;
* les prestations spécifiques à compléter ;
* un bouton de contact.

Ne pas afficher de disponibilité en temps réel et ne pas promettre de place disponible.

PAGE LA VIE AU QUOTIDIEN

Présenter l’établissement comme un lieu de vie.

Créer les sections suivantes :

* Les repas et la cuisine préparée sur place
* Le linge entretenu sur place
* Les activités et animations
* Les espaces communs
* Les chambres
* Les jardins et espaces extérieurs

* L’accompagnement au quotidien

Ne pas inventer le programme des activités, les menus, la composition des équipes ou les soins proposés.

Prévoir des blocs facilement modifiables quand Yasmina transmettra les textes et visuels définitifs.

PAGE TARIFS ET ADMISSION

Créer une page très claire destinée aux familles.

Sections :

1. Comprendre les tarifs
2. Tarifs d’hébergement

4. Hébergement temporaire
5. Accueil de jour
6. Aides ou prises en charge possibles

8. Documents à télécharger
9. Personne à contacter

Ne renseigner aucun montant tant que la grille tarifaire officielle n’a pas été transmise.

Utiliser des tableaux lisibles avec la mention :
« Tarifs à compléter à partir de la grille officielle de l’établissement. »

Prévoir les téléchargements suivants :

* dossier d’admission ;
* livret d’accueil ;
* flyer de l’accueil de jour ;
* autres documents utiles.

Ne pas créer de formulaire de demande d’admission en ligne.

PAGE GALERIE

Créer une galerie moderne, légère et adaptée au mobile.

Filtres proposés :

* Tout voir
* Extérieurs
* Espaces communs
* Chambres
* Activités
* Repas
* Événements

Cliquer sur une image doit ouvrir une visionneuse accessible avec navigation précédente et suivante.

Les images doivent être optimisées en WebP ou AVIF, chargées progressivement et accompagnées de textes alternatifs.

Ne pas intégrer automatiquement toutes les photos Facebook. Les photos seront sélectionnées avant publication.

PAGE FAQ

Créer une FAQ avec accordéons accessibles.

Prévoir provisoirement les questions suivantes, sans inventer les réponses :

* Comment déposer un dossier d’admission ?
* Quels documents faut-il fournir ?
* Quels types d’accueil proposez-vous ?
* Proposez-vous un hébergement temporaire ?
* Comment fonctionne l’accueil de jour ?
* Peut-on visiter l’établissement avant une admission ?
* Que peut apporter un résident dans sa chambre ?
* Comment se déroulent les repas ?
* Quelles activités sont proposées ?
* Comment contacter un résident ?
* Quels sont les horaires de visite ?
* Comment sont calculés les tarifs ?

Afficher « Réponse à compléter avec l’établissement » lorsqu’une réponse officielle n’a pas encore été transmise.

La structure de la FAQ doit permettre d’ajouter facilement les questions les plus fréquemment posées à la secrétaire.

PAGE CONTACT

Créer une page avec :

* adresse complète ;
* téléphone cliquable ;
* adresse e-mail cliquable ;
* carte Google Maps ;
* itinéraire ;
* liens vers les réseaux sociaux ;
* horaires avec la mention « À compléter ».

Ne pas créer de formulaire de contact dans cette première version, car cette fonctionnalité reste à confirmer.

Prévoir néanmoins la possibilité de l’ajouter ultérieurement sans refaire la page.

CONTENU ET TON RÉDACTIONNEL

Le ton doit être :

* chaleureux ;
* rassurant ;
* simple ;
* humain ;
* respectueux ;
* transparent ;
* compréhensible par les familles.

Éviter :

* le vocabulaire commercial ;
* les superlatifs non justifiés ;
* les formulations infantilisantes concernant les personnes âgées ;
* les promesses médicales ;
* les textes trop longs ;
* le jargon administratif non expliqué.

Utiliser « résidents », « familles », « proches » et « personnes accueillies ».

FONCTIONNALITÉS TECHNIQUES

Construire le site avec React, TypeScript et une structure de composants réutilisables.

Le site doit être :

* responsive ;
* rapide ;
* compatible avec les navigateurs récents ;
* facilement exportable et hébergeable ;
* sans dépendance obligatoire à une base de données ;
* simple à maintenir ;
* accessible selon les bonnes pratiques WCAG ;
* optimisé pour le référencement local.

Centraliser tous les contenus modifiables dans des fichiers ou objets clairement identifiés afin de faciliter les changements de textes, coordonnées, tarifs, liens, documents et médias.

Prévoir des composants réutilisables pour :

* les unités d’hébergement ;
* les solutions d’accueil ;
* les téléchargements ;
* la galerie ;
* les questions fréquentes ;
* les coordonnées ;
* les boutons d’appel à l’action.

RÉFÉRENCEMENT

Prévoir pour chaque page :

* une balise title unique ;
* une meta description ;
* un seul titre H1 ;
* une hiérarchie H2 et H3 cohérente ;
* des URL simples en français ;
* des données Open Graph pour le partage sur Facebook ;
* un sitemap.xml ;
* un fichier robots.txt ;
* des textes alternatifs pour les images.

Expressions importantes à utiliser naturellement :

* EHPAD à Dumbéa
* maison de retraite à Dumbéa
* établissement pour personnes âgées en Nouvelle-Calédonie
* hébergement temporaire pour personnes âgées
* accueil de jour à Dumbéa
* Les Jardins d’Eleusis

PERFORMANCES ET CONFIDENTIALITÉ

* Optimiser et compresser les images.
* Utiliser le chargement différé des images, vidéos et de la carte.
* Éviter les scripts inutiles.
* Ne pas installer d’outil de suivi publicitaire.
* Ne pas afficher de bandeau cookies si aucun cookie non essentiel n’est utilisé.
* Prévoir une politique de confidentialité.
* Protéger les coordonnées contre les usages automatisés lorsque cela est raisonnablement possible.

LIVRABLE ATTENDU

Commence par créer la structure complète du site avec toutes les pages, la navigation, le pied de page et des emplacements médias élégants.

Utilise de vrais textes uniquement pour les informations déjà confirmées.

Pour toutes les informations manquantes, affiche clairement « Contenu à compléter » dans le code et dans les données de démonstration.

Le premier rendu doit déjà être professionnel et utilisable comme maquette de validation avec la direction de l’établissement, tout en restant facile à enrichir lorsque les photos, vidéos, tarifs, documents et réponses définitives seront transmis.
